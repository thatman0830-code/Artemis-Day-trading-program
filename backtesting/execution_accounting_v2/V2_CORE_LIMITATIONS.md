# V2 Core Limitations

Completing V2 Core does **not** authorize or establish:

- live trading readiness;
- broker integration;
- profitable performance;
- acceptable untouched-OOS performance;
- authoritative roll, funding, or instrument data;
- deployment approval.

Further blockers include independently sourced effective-dated economic facts,
complete untouched-OOS datasets, at least 200 finalized untouched-OOS trades per
market, successful market-specific economic hurdles, required stress/ruin
evidence, operational security review, broker/exchange integration specifications,
paper validation, and explicit owner deployment authorization.

Probability-of-ruin output is empirical over supplied deterministic paths, not a
forecast. OHLC execution remains a conservative bar model rather than an order-book
or queue simulator. No result should be presented as a profitability guarantee.
