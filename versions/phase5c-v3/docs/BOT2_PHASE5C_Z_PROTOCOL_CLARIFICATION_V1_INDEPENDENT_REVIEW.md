## Disposition

The proposal's primary conditional paired comparison is well specified in several important respects: outcome-blind `U`, pre-inference availability masks, symmetric abstention handling, exact paired denominators, output-failure blocking, and explicit coverage reporting. Approval is nevertheless withheld because (1) the prospective matured-prior stream in §5 changes or materially settles A0's prior-source behavior, so this is not solely an evaluation clarification; (2) the selective comparison in §12 uses output-dependent retained-row intersections and therefore does not meet the requested same-ID/no-result-based-omission rule for all comparative metrics; and (3) the manifest leaves the interaction between A0 abstention and calibration fit rows insufficiently bound for this strict review.

No code or tests were changed or run. No protected archive, predictions, probabilities, outcomes, metrics, scores, P&L, or performance data were accessed. The existing repository worktree was dirty before this review; implementation files were not modified by this pass. **NOT APPROVED — CLARIFICATION BLOCKERS REMAIN.**
