# #29.7.2.14 — Exact Mechanical Trade Sequence / Path Statistics

## Status
LOCKED_AND_IMPLEMENTABLE. Read-only. Describes the order and path of finalized trades without interpreting why the path occurred.

## Ownership
MAY READ finalized records (trade_id, setup_id, closed_time, opened_time, trade_result, NetPnL/GrossPnL, NetR/GrossR, equity, direction, setup type). MAY CALCULATE chronological sequence, sequential index, result/R/P&L sequences, W/L/BE transitions, runs, transition counts/probabilities, path snapshots. MAY NOT modify accounting/equity/results, reopen/reorder trades, reinterpret entry/exit, or compute expectancy/PF/drawdown/recovery/strategy quality.

## Canonical Definition
- Ordering = canonical `closed_time ASC` (tie-break deterministic `trade_id`), immutable once finalized.
- Result sequence sourced from finalized `TradeResult` — **never** inferred from NetPnL.
- R sequence from `NetR`; P&L sequence from `NetPnL` (consumed as finalized).
- Nine transition types (`{WIN,LOSS,BE}²`); every adjacent pair → exactly one transition; `TransitionCount = max(N−1, 0)`.
- Transition probabilities: `P(S→X) = Count(S→X) / Count(S as non-final state)`; final trade has no outgoing transition.
- Breakeven is its own state (never merged with WIN/LOSS).
- Runs = consecutive identical results; `ResultRun` object; `MaxWinRun` / `MaxLossRun` (0 if none) — **consumes** [[#29.7.2.8 Streak Statistics]], does not redefine streaks.
- Current run = run containing the latest finalized trade (point-in-time).
- Snapshots (`TradeSequenceSnapshot`) for point-in-time path without future contamination.
- Setup/instrument/timeframe/direction/day/week/month grouping is grouping only; does not change the canonical global sequence.

## Empty / Single / Missing
Empty: sequence `[]`, transitions 0, runs 0, MaxWinRun/MaxLossRun 0, CurrentRun/CurrentTrade `NULL`, transition probabilities `NULL`. Single: length 1, transitions 0, one run. Missing trade: not manufactured.

## Duplicate Handling — SUPERSEDED
Historical §19 wording ("Duplicate Trade Record → Excluded → canonical trade remains authoritative") is **`SUPERSEDED_BY_AMENDMENT_001_C2`**. Canonical behavior: `duplicate trade_id → DATA_INTEGRITY_ERROR → fail-closed → no finalized .14 snapshot`. Historical wording preserved in [[Appendix A — Recovered Historical Transcript]].

## Hard Invariants
`SequenceLength = N`; `TransitionCount = max(N−1,0)`; every trade in exactly one run; Σ run lengths = N; Σ transition counts = `max(N−1,0)`; BE is its own state; no transition after final trade; result consumed from finalized accounting; future trades cannot alter historical positions; current run = run of latest trade.
