# #29.7.2.20 — Strategy Return Covariance

## Status
LOCKED_AND_IMPLEMENTABLE (§04.4 + FINAL LOCKED DEFINITION; input schema resolved by Amendment 001 C3).

## Canonical Definition
Sample (N−1) covariance of period-aligned strategy returns. **Return basis = period-aligned `net_r`** consumed from [[StrategyPeriodReturnObservation]] (same aligned population as [[#29.7.2.19 Strategy Return Correlation]]). Point-in-time: `CovarianceAt(T)` uses only observations with `period_end <= T` finalized and eligible at that point. **Missing ≠ zero**; finalized `net_r = 0` valid; NULL ≠ 0; `n < 2` → NULL. Covariance itself is order-independent, but the underlying observation set obeys the chronological finalized-record rules (no future observation enters a point-in-time calculation). Duplicate strategy/timestamp observations → global fail-closed `DATA_INTEGRITY_ERROR`. Object: `StrategyCovariance` / `StrategyCovarianceMatrix`. Configurable: covariance mode / rolling window ([[Runtime Configuration Registry]]).

## Hard Invariants
- sample (N−1); missing ≠ zero; NULL ≠ 0; `n<2` → NULL
- same aligned population as .19; point-in-time `period_end <= T`
- duplicate observation → `DATA_INTEGRITY_ERROR` fail-closed; no look-ahead; immutable
