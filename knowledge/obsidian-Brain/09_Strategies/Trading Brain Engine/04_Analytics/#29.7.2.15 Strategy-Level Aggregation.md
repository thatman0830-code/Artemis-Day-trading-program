# #29.7.2.15 — Exact Mechanical Strategy-Level Aggregation

## Status
LOCKED_AND_IMPLEMENTABLE. Deterministic, read-only. Observes finalized history; never modifies/reinterprets/reconstructs/overrides.

## Ownership
Owns strategy-level trade counts, W/L/BE, gross/net P&L, gross/net R, win rate, expectancy, profit factor, cumulative, equity, drawdown, recovery, streaks, distribution, time-period statistics, aggregation across qualifying trades. Does NOT own setup qualification/entry/sizing/execution/exit/costs/individual accounting/strategy definitions/optimization/parameter selection/forward-looking conclusions.

## Canonical Definition
- **Strategy identity:** every finalized trade carries a deterministic immutable `strategy_id` (e.g. `CONTINUATION`, `REVERSAL_1`) supplied upstream — never inferred from P&L/R/direction/timeframe/result.
- **Dataset:** `StrategyTrades(S) = finalized TradeAccounting where strategy_id = S`. Only finalized trades eligible.
- **Time:** canonical timestamp `closed_time`; interval `[start_time, end_time)` (Amendment 002 R1).
- **Conservation:** `TradeCount = W+L+BE`; `StrategyNetPnL = Σ Trade.NetPnL`; `StrategyGrossPnL = Σ Trade.GrossPnL`; `StrategyNetR = Σ Trade.NetR`; `StrategyGrossR = Σ Trade.GrossR` (never recomputed from aggregate P&L).
- Win rate = `WinCount / TradeCount` (BE remains in denominator); expectancy, profit factor inherit .3/.4; cumulative/equity/drawdown/recovery/streaks/distribution/time-series inherit .5–.13 unchanged.
- Strategy equity: `StrategyEquity_i = StrategyStartingEquity + Σ NetPnL_1..i` (starting equity explicitly supplied, never guessed).
- Empty strategy: additive totals 0; observation-dependent statistics `NULL`. Zero ≠ NULL.
- Multiple strategies are not auto-merged; portfolio combination is a separate operation ([[#29.7.2.16 Portfolio-Level Aggregation]]). May expose comparison facts but never declares one strategy superior.
- Object: `StrategyPerformance { … with references to equity/drawdown/recovery/streak/distribution/period series … source_trade_ids; calculation_timestamp; calculation_version }`.

## StrategyPeriodReturnObservation (derived)
The `StrategyPerformance` object does not itself emit the canonical period observation; it is **derived** from .15 §time-series + [[#29.7.2.9 Time-Series — Period Statistics]] + Amendment 001 C3. `net_r = Σ finalized Trade.NetR within the strategy-period` (never NetPnL/arbitrary-risk). See [[StrategyPeriodReturnObservation]]. No second return definition invented.
