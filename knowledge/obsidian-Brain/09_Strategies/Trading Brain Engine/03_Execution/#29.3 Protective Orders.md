# #29.3 — Exact Mechanical Stop & Target Order Model

## Status
LOCKED_AND_IMPLEMENTABLE

## Ownership
Constructs the OCO protective stop + target orders from the already-selected `StopPrice` ([[#13 Stop-Loss Selection]]) and target ([[#24 LRL Selection]], ≥2R owned by [[#27 Setup Qualification]]). Does not select the stop price or resolve exits ([[#29.4 Exit Resolution]]).

## Canonical Definition
- Protective stop order built from the exact immutable `StopPrice`.
- Target order = nearest-structure LRL at ≥2R.
- OCO relationship: one fills, the sibling cancels.
- Directional invariants enforced: long stop `< entry`, long target `> entry`; short stop `> entry`, short target `< entry`.

## Hard Invariants
- stop order price = exact `StopPrice` (never recomputed here)
- directional invariants → else `PROTECTIVE_ORDER_INVALID` / `TARGET_ORDER_INVALID`
- OCO: exactly one protective order executes; the other cancels
